# museum-intro

Заставка на главной museum.eprisjournal.com: несколько лучших работ подряд,
каждая в раме на тёмной стене. Камера медленно подъезжает или проходит вдоль,
кадры меняются жёсткой склейкой, внизу подпись. В конце идут название музея
и кнопка входа. Одна работа держится 2,3 с, восемь работ вместе с финалом
занимают около 20 с. «Skip», Esc и Enter закрывают заставку, клик или пробел
листают вперёд.

Музей собирается на VPS (`/opt/museum`, `build-index.py`), его исходников в
этом репозитории нет. Здесь лежит версионированная копия файла, как у
остальных скриптов в `ops/`.

## Установка

1. Скопировать `museum-intro.js` в корень сайта музея: `/opt/museum/…/museum-intro.js`.
2. В шаблон главной в `build-index.py`, перед `</body>`, вставить список работ
   и сам скрипт:

```html
<script>
window.MUSEUM_INTRO = {
  works: [
    { src: '/media/…/work-1.jpg', title: 'Назва', artist: 'Автор', year: '2021', frame: 'gold' },
    { src: '/media/…/work-2.jpg', title: '…', artist: '…', year: '…', frame: 'black' }
    // 3–8 работ; frame: gold | black | white, без него рамы чередуются
  ],
  text: { title: 'EPRIS Museum', enter: 'Enter the museum', skip: 'Skip' }
};
</script>
<script src="/museum-intro.js" defer></script>
```

Если работы проще отметить прямо в разметке, список можно не передавать.
Тогда скрипт возьмёт `<img data-intro data-intro-title="…" data-intro-artist="…">`,
а если таких нет, то все крупные картинки главной (подписью станет `alt`).

## Поведение

- Показывается при каждом открытии главной (`/` или `/index.html`).
- `?intro=0` в адресе отключает заставку, `?intro=1` показывает её на любой
  странице (удобно для проверки).
- Если загрузилось меньше трёх картинок, заставки нет. Самую медленную
  картинку скрипт ждёт не дольше 4 с и показывает то, что успело загрузиться.
- При `prefers-reduced-motion` камера не двигается, кадры просто сменяются.
